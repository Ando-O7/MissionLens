## 1. AAA のゲームから取り入れる考え方

形は真似しない。取り入れるのは次の考え方(各タイトルの画面についての一般的な知識にもとづく。資料を取り寄せて照合したものではない)。

| 考え方 | よく知られた例 | Mission Lens での形 |
|---|---|---|
| 色は絞る。白〜灰が主役で、差し色は 1 つの意味だけ | デス・ストランディング、Mirror's Edge(「行ける所」だけ赤) | シアンは「選べる / 選んでいる」だけ |
| ラベルは小さく、数字は大きく | デス・ストランディング、フライトシミュレーターの計器 | 区間の数値は 64、単位と名前は 24 / 20 |
| 情報は、要るときに、物のそばに出す | デス・ストランディングの地形スキャン、Horizon の Focus、The Division の空間 UI | 区間の数値は模型から線で引き出す。現地では印と次の地点だけを景色に出す |
| 箱で囲まず、細い線と余白で区切る | デス・ストランディング、Destiny 2、Hitman のメニュー | 四隅の飾りと枠をやめ、上の細い線 1 本と余白 |
| 情報は体や道具に持たせ、視界に貼り付けない | Dead Space、Half-Life: Alyx、Lone Echo(VR) | 詳細は手のパネル(現状どおり)。視界の帯は 1 行 |
| 使っていないときは弱める | 多くの AAA の「動的 HUD」 | 現地の帯は、変化がなければ数秒で 60% に薄くする |
| 色だけに頼らない(色覚への配慮) | 近年の AAA の標準 | 出どころは、印の形 + 言葉 + 線の種類でも区別する |

取り入れないもの: 特定のゲームの書体・アイコン・記号、走査線や発光などの「SF 風」の飾り、数値のカウントアップのような演出。

## 2. ルール

### 2.1 文字

書体を 1 組に決め、太字の合成をやめる(いまは既定の Liberation Sans に合成の太字で、これが「よくある見た目」の一因)。

- **英数字: Barlow**(OFL)。細身で数字が読みやすく、計器や標識に近い字形。ラベルは Barlow Semi Condensed。
- **日本語: Noto Sans JP**(OFL、いまも使用)。Regular に加えて Medium を足す。
- 数字は等幅(桁がそろう)。

| 段階 | 大きさ | 太さ | 色 | 使いどころ |
|---|---|---|---|---|
| Display | 64 | Light(300) | Ink | 主役の数字(距離、時刻など) |
| Title | 42 | Regular | Ink | 作業名、帯の 1 行 |
| Heading | 34 | Medium | Ink(補助は Soft) | 地点名、記録の名前 |
| Body | 28 | Regular | Ink | 読む文、ボタンの文字(Medium) |
| Label | 24 | Medium、大文字 + 字間 0.09em | Gray | 見出しのラベル、単位 |
| Note | 20 | Regular | Gray(クレジットは Dim) | 注記、出どころの語 |

- 太字(700)は使わない。強さは大きさと色で付ける。
- 日本語のラベルは大文字化がないので、Medium と字間だけ。

### 2.2 余白

パネルの画素で 8 の倍数: **8 / 16 / 24 / 40 / 64**。パネルの縁 64、まとまりの間 40、線の前後 24、ラベルと中身の間 16、数字と名前の間 8。直書きの数字はこの 5 つに寄せる。

### 2.3 色(役割ごと。`MLPanel` の定数をそのまま使う)

| 色 | 役割 |
|---|---|
| Ink | 主役: 読む文、数字、選択中の文字、地図の線と印 |
| Soft | 補助の文、景色の上の注記 |
| Gray | ラベル、単位、注記 |
| Dim | クレジット、無効 |
| **Cyan** | **選べる / 選んでいる、だけ。** 主ボタンの地、ボタンの「›」、選択中の地点の下線・時間割の上線・地点の輪 |
| **Amber** | **実在しないもの(仮想・模擬)のラベルだけ。暗いパネルの上でだけ使う。** 地図と景色の上では使わない |
| Back | パネルの地。濃紺をやめ、色味のない黒 80%(パススルーの部屋の上で読むために地は残す)。枠なし |
| Line | 細い線。白 24%(弱い線は 12%) |

- **経路の色**: 白にする。経路は押せないので、シアンにしない。選んだ作業の区間は太い白 + 黒い縁、ほかの区間は細い白 60%。
- **傾斜の黄・橙・赤**: データの色としてそのまま。暖色は地図の上では傾斜だけの色にする。このため、Amber を地図と景色から外し、模擬の印は白の形で表す(いまは橙の札で、傾斜の橙と近い)。
- **「現在の作業」の橙の枠**: 白い「▼ THE MARSWALK IS HERE」の印に変える(出どころではなく状態なので、Amber を使わない)。

### 2.4 出どころの区別(色以外でも分かるように)

印の形・言葉・線の種類の 3 つで表す。色は補助。

| 出どころ | 印 | 言葉 | 色 | 線・地図での形 |
|---|---|---|---|---|
| NASA の観測 | ■ 塗りの四角 | NASA OBSERVATION | Ink | 画像に実線の細い枠 |
| NASA の記録 | ■ 塗りの四角 | NASA RECORD | Ink | 実線 |
| こちらの計算 | □ 抜きの四角 | OUR CALCULATION / OUR READING | Soft | — |
| 模擬 | ◇ 抜きのひし形 | SIMULATED | Amber(パネル上)/ 白(地図・景色) | 点線の柄に、抜きのひし形 |
| 仮想 | ◇ 抜きのひし形 | HYPOTHETICAL | Amber(パネル上) | — |

塗り = NASA のもの、抜きの四角 = NASA のデータからこちらが出したもの、ひし形 = 実在しないもの。白黒にしても区別できる。いま「こちらの計算」に使っているシアンは、選べるもの専用にするので外す。

### 2.5 線・角・形

- 線: 細い線 2 画素(1 画素は VR でちらつくので使わない)。選択中は 3〜4 画素。地図の柄も 2 画素。
- 角: パネルは 0(角丸のカードをやめる)。ボタンと時間割のマスは 4。丸は地点の輪だけ。
- パネル: 四隅のカギ型と枠をやめる。上の細い線 1 本と地だけ。
- 床: シアンの格子をやめ、色味のない暗い床に、机の下だけ少し明るいぼかし。パススルーでは床を描かない(現状どおり)。

### 2.6 ボタン

- 主ボタン(1 画面に 1 つ): シアンの地に暗い文字。
- 副ボタン: 細い白い枠、白い文字、シアンの「›」。
- 文字だけのボタン: 白い文字にシアンの「›」。
- 選択中: シアンの線(下線 / 上線 / 輪)+ 白い文字。地をシアンで塗らない。

### 2.7 動き

| 場面 | 動き |
|---|---|
| 出る | 180 ms で薄い状態から現れ、8 画素分だけ上がる。弾まない |
| 消える | 120 ms |
| 中身の切り替え(作業を選ぶ) | 120 ms の入れ替え。数字は数え上げない |
| 指す(ホバー) | 80 ms で枠が明るくなる |
| 押す | 80 ms シアンで光り、120 ms で戻る。音と振動は現状どおり |
| 景色の上の印 | 指したとき・記録したときに 150 ms で出る |
| 現地の帯 | 変化がなければ 4 秒で 60% に薄くなり、作業が変わる・指すと戻る |

## 3. 画面ごとの主役

| 画面 | 主役(その場面の判断に使う 1 つ) | 弱めるもの |

## 4. モックで見せていないこと、分からないこと

- **ヘッドセットでの見え方**: 細い線(2 画素)と Light の数字がちらつかないか、景色の上の文字(影つき)が明るい地面で読めるか。モックでは判断できない。段階 4 で実機で確かめる。
- **日本語**: 現地の帯だけ日本語のモックを作った。ほかの画面は英語だけ。
- **入れていない画面**: タイトル、手首パネル、メニュー、タイマー、振り返り、別のセッションが追加中のパネル。ルールは同じ。
- **書体の追加**: Barlow と Noto Sans JP Medium をアプリに入れる必要がある(どちらも OFL。APK は約 +5 MB。提出フォームの外部リソースの一覧にも足す)。
