## 達成したこと(Editor の画面で確認)

1. 机の模型が「写真の板」から「地形図の模型」になった。拡大すると等高線の束で斜面の形が読める(B への登り)。
2. 机そのものに、方位・縮尺・出典・等高線の間隔がある。手のメニューを出さなくても地図が読める。
3. 地形を指すと、その点の標高と傾斜が出る。傾斜は区分の色(10° / 15° / 20°)で出る。
4. すべてのパネルが同じ枠になった。
5. 全体の通し確認(27 項目)は通り、コンソールのエラーは 0。

## 未達(はっきり足りないもの)

1. **実機での確認が無い。** 手のメニュー、指で押す、両手の伸縮、等高線の細さ(ヘッドセットではちらつく可能性)、指した点の札の出方(手が模型を向くたびに出るので、うるさいかもしれない)。
2. 歩行中の景色。地形モデルの地面がぼやけて見える。参考作の水準からもっとも遠い場面。
3. 文字の体系。大きさの種類が多く、小さい灰色の注記は 0.9 m 先では読みにくい可能性がある。
4. 音。合成の単音で、厚みと空間が無い。
5. 読み物のパネル 2 枚の置き方(机に立てたまま)。

## 次に手を付ける候補(効果の大きい順の見立て)

1. 実機の所見とログで、手のメニューの角度・等高線の太さ・指した点の札の出方を合わせる。
2. 文字の大きさを 4〜5 段階に整理し、注記の最小の大きさを上げる(全パネル)。
3. 歩行中の表現を決める: いまの画像のまま / 画像を薄くして等高線と格子の「模型の見え方」に寄せる(酔いに影響するので実機で比べる)。
4. パネルの中身を順に出す、数値を滑らかに変える。
5. ルートに 50 m ごとの目盛り。傾斜の凡例を机の縁へ。
