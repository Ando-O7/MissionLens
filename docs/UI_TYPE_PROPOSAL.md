## 1. 文字の段階(6 段階 + ロゴ)

20 から 1.2 倍ずつの列。`MLPanel` に定数として 1 か所に置く。

```csharp
// The type scale. Every size on every surface is one of these (pixels on the surface).
public const float Display = 64, Title = 42, Heading = 34, Body = 28, Label = 24, Note = 20;
```

| 段階 | 定数 | px | 太さ | 色 | 使うところ |
|---|---|---|---|---|---|
| 表示 | `Display` | 64 | 太 | Ink | 1 面に 1 つまでの数字・語。タイマーの時刻、到着・完了の帯の主文 |
| 大見出し | `Title` | 42 | 太 | Ink(選択中は Cyan) | その面の主役。左ボードの作業名、地点の札、標高の札の値、タイトルの副題 |
| 見出し | `Heading` | 34 | 太 | Ink(注意は Amber) | 狭い面の主役と、大きく見せる数値。時間割の作業名、現地の帯の主文、手首パネルの作業名、縮尺、区間の数値 |
| 本文 | `Body` | 28 | 細(主ボタンは太) | Ink | 判断に使う文。すること、理由、NASA の記録、確認項目。主ボタンの文字 |
| 補足 | `Label` | 24 | 太 = 小見出し・出どころの札・副ボタン / 細 = 補足の文 | 小見出し: Gray。出どころ: Ink(NASA)・Cyan(こちらの計算)・Amber(模擬・仮想)。補足の文: Soft | 小見出し、出どころの札、副ボタン、作業の番号や時刻 |
| 注記 | `Note` | 20 | 細 | Gray(クレジットとビルド表示だけ Dim) | 出どころの注記、単位、凡例、クレジット |
| (ロゴ) | — | 108 | 太 | Ink | タイトルの「MISSION LENS」だけ。例外として残す |

使い方の決まり(段階 2 で守ること):

1. 主役と脇役は 2 段階あける。42 ↔ 28 ↔ 20、または 34 ↔ 24。隣り合う段階(28 と 24 など)は、太さか色も変えて使う。
2. 日本語と英語は同じサイズ。入らないときは、サイズではなく文を短くする。
3. 灰色は役割で固定する。読む文 = Ink、補足 = Soft、注記 = Gray、クレジット = Dim。配色そのものは変えない。
4. 出どころは色つきの札か小見出しで示す(NASA = Ink、こちらの計算 = Cyan、模擬・仮想 = Amber。タイトルの凡例と同じ色)。文の後ろに毎回かっこ書きで足さない。
5. 英語の全部大文字は、補足(太)の小見出しと札だけ。
6. 行送りはサイズの約 1.3 倍(28 → 36、24 → 31、20 → 27)。

## 3. 「1 : 25」の名前

1 : 25 は、地形モデルを自分のまわりに 25 分の 1 で広げる見方。100 m の区間が 4 m になり、机の地図より大きく、実寸より小さい。登りの形と、どこがどこの陰になるかを、上から見渡すためのもの(軌道のデータだけ。`UI_DECISIONS.md` の 14 で「要るかどうかは実機で判断」としたまま)。

いまの名前は縮尺だけで、何のためかが出ていない。また「下見」を、この 1 : 25 と、先の地点の実画像の 2 つに使っている。

| 場所 | いま(日 / 英) | 提案(日 / 英) |
|---|---|---|
| 右ボードのボタン | 下見 1 : 25 / Preview 1 : 25 | **地形を見渡す / Overlook**。下に注記で「地形モデル · 1 : 25」 |
| 手首パネルの切り替え | 1 : 25 ・ 実寸 / 1 : 25 ・ True scale | **見渡す 1 : 25 ・ 実寸 1 : 1** / Overlook 1 : 25 ・ True scale 1 : 1 |
| 手首パネルと帯の見出し | ルートの下見 · 1 : 25 / ROUTE PREVIEW · 1 : 25 | 地形を見渡す · 1 : 25 / OVERLOOK · 1 : 25 |
| 「下見」という語 | 1 : 25 と、先の地点の実画像の両方 | 先の地点の実画像だけに使う |

「B に立つ」「B の実画像へ」「机へ」「地形モデルへ出る」は、することが名前に出ているので変えない。ボタンの内部の名前(自動確認が押す `key`)も変えない。
