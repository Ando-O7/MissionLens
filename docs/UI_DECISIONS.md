# UI/UX の判断記録

最終更新: 2026-11-14 22:25 JST / Claude Code

2026-11-14 の企画セッションの連絡により、これまでの UI/UX 案は確定要件を除いて参考扱いになり、設計は各開発セッションに任された。この文書は、重要な UI 案の状態(採用 / 検討中 / 見送り)と理由を残す。対象は Quest 3 の MR / VR の空間 UI。「擬似版」は `experiments/spatial/index.html`(デスクトップでの代役)を指す。もう一方の AI セッションの UI は見ていない。

**どれも人の手と実機では未確認。** 1〜11 は擬似版で、ヘッドレス Chrome での操作の自動確認(25 項目)と画面の目視まで。23 以降は Unity 版(`unity/Assets/MissionLens/`)で、Editor の Play をデスクトップ用のカメラで動かし、開始から終了までを通しで実行して画像で見たところまで。文字の大きさや置き場所は Quest での見かけの角度に換算して決めたが、実機では見ていない。

## 設計の軸

- **PLAN は机が画面、FIELD は景色が画面。** 部屋では両手と視野が空いていて読む時間がある。現地では手も目も地形に向いている。
- **データはメニューから選ぶものではなく、判断の場面に出るもの。** 「歩けるか」に傾斜、「なぜここか」に分光と試料記録、「何が見えるか」に実画像。
- **出どころは一目で分かるようにする。** NASA の観測 / NASA の記録 / こちらの計算 / 仮想の計画 / 模擬の記録。

## 採用

| # | 案 | 理由 | 擬似版 |
|---|---|---|---|
| 1 | PLAN は「机上の模型 + 奥のブリーフィングボード + 手前の時間割」。PLAN では手首パネルを使わない | 手首パネルは視界の一部を塞ぎ、模型と説明を同時に見られなかった。部屋には置く場所がある | あり |
| 2 | ボードに「科学目標 → この地点へ行く理由 → NASA の根拠」を並べる。根拠は、その地点の実画像の切り抜き、試料記録、CRISM | 以前は科学目標が画面のどこにも無かった。課題の Science と「NASA データが核」に直接応える部分 | あり |
| 3 | 時間割を 1 本の帯にする。区切りを選ぶと作業・地点・区間が連動し、区間の距離・登り・最大傾斜が出る | 作業順と地点の連動。13 行の表より読む量が少なく、時間の配分が形で分かる | あり |
| 4 | 机上の模型は、この Marswalk が使う範囲だけを約 1 : 570 で出す(以前は対象範囲の全体を 1 : 1500) | 1 : 1500 では地点 A・B・C が画面上で 17 px の中に重なった。局所という軸に反する | あり |
| 5 | レイヤーは「傾斜」と「分光」の 2 つ、どちらか一方 | 判断に結びつくものだけにする。重ねると読めない | あり |
| 6 | FIELD で常に出すのは視界下の細い帯だけ。地点名、現在の作業と進み、経過時間、方位、次の地点が視界の外にあるときの矢印 | 景色が主役。宇宙服の HUD を想定した最小限 | あり |
| 7 | 手首パネルは上げたときだけ出す(擬似版では Space)。確認項目、NASA の記録、移動、机へ戻る | 詳細は必要なときだけ。常時表示だと景色を塞ぐ | あり |
| 8 | 景色を指して「候補」を記録する(模擬)。指した方向と地形モデルの交点を地図座標にし、机上の地図に印が残る。対応する確認項目に自動で印が付く | FIELD から PLAN への向きの連携。実画像と地図が同じ座標にあることを、操作で示せる。パノラマを VR で見るだけの既存ツールとの違いになる | あり |
| 9 | PLAN → FIELD は、選んだ地点を軸に模型が広がって入る。着いたときの向きは、ボードで見た切り抜きと同じ方位 | 計画で見た景色が、そのまま目の前に出る | あり |
| 10 | 地点の実画像は公式パノラマのある 4 地点だけ。その間は軌道データの地形モデルで、そう明示する | 観測の無い場所を実測のように見せない | あり |
| 11 | 画面の要素ごとに出どころを書く(NASA OBSERVATION、NASA record、our calculation、simulated、hypothetical) | 実データと仮想の区別 | あり |

## 検討中

| # | 案 | いまの考え |
|---|---|---|
| 12 | 手に持つレンズ。机上の模型にかざした円の中だけ別のレイヤーが見える | 名前と一致し、手で扱える。ただし 5 のボタンで用は足りている。時間が余れば試す |
| 13 | 机上の模型を手でつかんで回す・寄せる | 実機でしか良し悪しを判断できない。Quest で見る手段が決まってから |
| 14 | 1 : 25 で地形の中を歩く「ルートの下見」 | 残してあるが、位置づけを PLAN の下見に変えた。要るかどうかは実機で判断 |
| 15 | FIELD で観測対象そのものに印を付ける(NASA のコア採取位置など) | 記録上の位置は停止点から約 2 m。パノラマの近景は数度ずれるので、正確な印にならない。いまは「この停止点から約 3 m 以内」と文で示すだけ |
| 36 | FIELD で実際の火星の音(Perseverance のマイクの録音)を流す | 実データなので方針には合う。ただし扱うデータの追加で、録音地点もこの 4 地点ではない。入れるかどうかはユーザーの判断。いまは入れていない |

## 採用(Unity 版で追加、2026-11-14 22:25)

| # | 案 | 理由 |
|---|---|---|
| 23 | タイトル → 「Begin briefing」→ 出発点から模型が広がるオープニング(約 4 秒) | 最初の画面で、NASA の観測 / こちらの計算 / 模擬の区別を伝える。ヘッドセットでは、押した時点の向きに机を置くので、位置決めの合図も兼ねる。デモの開始点が毎回同じになる |
| 24 | 机から「Stand at X」で立つのは**先の地点の下見**で、Marswalk の現在地は動かさない。FIELD 本体へは「Begin / Resume Marswalk」で、Marswalk が今いる地点から入る。地点間は計画したルートでだけ移動する | 以前は机から任意の地点に立つと現在地がそこへ飛び、「次は A へ」と出るなど作業順と食い違った。PLAN は確認、FIELD は実行、という役割がそのまま操作になる |
| 25 | FIELD の帯の右に「いま必要な 1 操作」(Walk to X / Complete task / Review at the table / Back to the table)と、Panel、Table を置く | 手首パネルを開かなくても先へ進める。机へ戻る道が常に 1 手で届く。手の認識が不安定でも詰まらない |
| 26 | 最後の作業のあとに「Marswalk complete」を出し、机のボードを振り返りに変える(記録した候補と、この実行が測っていないもの)。やり直しは 2 回押し | アプリとして終わりがあり、続けて次の人に渡せる。模擬であることを結果の画面でも書く |
| 27 | 地点ラベルは地面から引き出し線で浮かせ、地面にリングを置く。近い地点同士は左右に振り分け、それでも重なれば上へずらす | ラベルが地点そのものを隠していた。BASE から見ると A・B・C がほぼ同じ方向で重なっていた |
| 28 | 次の地点に縦の標識。実画像の上では、これから歩く区間のルートだけを出し、足元では消す | 景色が主役。足元のルートは 2 m 上から見ると太い帯になって実画像を塞いだ |
| 29 | 指したボタンに枠、押すと光る。操作音とコントローラーの振動。小さいボタンは近くを指せば届き、ピンチで光線がぶれても直前に指していたボタンが押される | 手の光線は押す瞬間に動く。時間割の 5 分の区切りは机上で幅 1.6 cm しかない。時間割には前後の送りボタンも付けた |
| 30 | 手もコントローラーも数秒見えないときは、視線を 1.4 秒止めたボタンが押される | 実機で指し示しが効かなかった場合でも審査で止まらないための保険 |
| 31 | 地形が動いている間(机 ↔ 現地、地点間の移動)は視野の周辺を暗くする。ヘッドセットのみ | 人は動かず地形が動く方式なので、周辺視野の流れを減らして酔いにくくする |
| 32 | パノラマより上の空は、画像の最上段の色を天頂へ延ばして埋める。画像の無い部分(車体の黒抜き)は、地形モデルを暗くして 1 m グリッドを引く | 以前は空が 1 色で、太陽側の明るさと合わず継ぎ目が出た。黒抜きはただの暗い面で未完成に見えた。どちらも観測ではないと手首パネルに書く |
| 33 | 机上の模型に側壁・台・凡例(北、100 m、縮尺、高さの倍率)。側壁は標高の目盛りだけの抽象的な面 | 模型として読める。地下の情報は無いので、地層のようには描かない |
| 34 | 音は合成の操作音だけ(ホバー、押下、記録、完了、到着、移動) | 反応が耳でも分かる。現地の環境音は入れない(見送り 37) |
| 35 | VR の間は手の輪郭線を出す | 部屋が消えると自分の手が見えなくなり、どこを指しているか分からなくなる |
| 16 | 部屋から火星へは、空の不透明度で連続して切り替える(以前は途中でパススルーを切っていた) | 机の上の模型が広がりながら、部屋が火星の空に置き換わる |
